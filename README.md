⚠️ Vulnerable App
A purposely vulnerable web application created for simulating cyberattacks as part of a midterm requirement. The app is designed to practice security testing and identify potential vulnerabilities.

📌 Overview
The Vulnerable App allows users to:

Simulate common cyberattacks (e.g., SQL Injection, Cross-Site Scripting)

Test and learn about web application security

Practice ethical hacking techniques in a controlled environment

This project was developed as part of a cybersecurity course requirement, with the goal of understanding vulnerabilities and defense mechanisms.
